# Live Japon caché

Page du live TikTok « Apprends le japonais avec moi » : un mot japonais toutes les ~25 s (voix japonaise native + explication en français), quiz, décor animé, musique koto.

Sur le téléphone : ouvrir la page dans Chrome, menu ⋮ > « Ajouter à l’écran d’accueil », puis lancer depuis l’icône (plein écran, sans barre d’adresse).

Source : dépôt TikTok-Japon, dossier `live/`.
